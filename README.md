# Selenium Test Automation Framework (POM + TestNG + Data-Driven + Extent Reports)

A scalable test automation framework built using Selenium WebDriver and TestNG. 
Implements Page Object Model (POM), data-driven testing, and detailed reporting using Extent Reports. 
Includes screenshot capture on test failure for better debugging and test analysis.

## Features

- Selenium WebDriver with Java
- TestNG framework integration
- Page Object Model (POM)
- Data-driven testing using DataProvider
- Extent Reports for HTML reporting
- Screenshot capture on test failure
- Handling dynamic elements using explicit waits
